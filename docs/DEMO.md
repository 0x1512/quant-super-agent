# Demo 剧本 — quant-super-agent 全流程展示

一条命令（~35 秒，全程离线，产物字节可复现）：

```bash
python examples/run_demo.py            # 快速模式：重放已录制的门禁素材
python examples/run_demo.py --full-gauntlet   # 完整模式：现场真跑 19 分钟门禁
```

产出：`work/demo/DEMO_REPORT.md` 一页汇总 + 各阶段产物目录。

**核心叙事（开场 30 秒）**：这不是一个"展示赚钱"的 demo，是一个展示
"为什么这套流水线产出的数字可以信、以及它如何高效淘汰不该信的候选"
的 demo。三个数字记住：22 秒筛 24 个因子、17 个死在快验证、幸存者
才配进 19 分钟的诚实门禁。

---

## Stage 0 — 钉死数据面（~10 秒）

屏幕上出现快照指纹、行数、宇宙规则。

**讲词**：所有后续阶段的输入是同一个 sha256 钉死的快照——300 只
2021 上半年成交额最大的股票、5 年日线、前收链复权。演示不依赖
今天的网络，任何人 clone 后跑出同样字节。

## Stage 1 — 因子工厂·快验证（~22 秒）

24 个公开文献因子（Jegadeesh-Titman 动量、Lehmann 反转、Amihud
非流动性、Bali 彩票因子、George-Hwang 52 周新高……每个都带出处），
一次扫描输出 leaderboard：IC、分组价差、train→val→oos 三期 IC。

**讲词（指着表格）**：看 train→oos 这一列的塌陷——榜首 train IC
+0.10 出头，oos 转负。这不是 bug，是市场：这批公开因子在 2025-26
的大票样本上集体衰减。快验证的价值就是**让它们死在 22 秒里，而不是
浪费 19 分钟门禁**。幸存者只有少数几个（mom_gap_12m、dist_52w_high、
vol_of_vol），它们才值得深查。

**互动点**：可以让观众任选一个因子 ID，现场讲它的文献出处（都在
`qsa/factorzoo.py` 的 catalog 里）。

## Stage 2 — 可交易性回测（即时）

top-3 候选的费后体检：超额年化、NW Sharpe、换手、容量、回撤、
train/val/oos 三期超额。

**讲词**：注意这里的标准变了——不是"IC 显著"，是**扣费后还剩多少、
能装多少钱、三期是否都活着**。triple-gate 一列 train 1.2 / val 0.6 /
oos 0.03，一眼看出"训练期 alpha，样本外归零"。成本、参与率、分区
全部是显式参数，没有暗含约定。

## Stage 3 — 诚实性铁三角（重放即时 / --full-gauntlet 19 分钟）

Scenario A（研报隔夜跳空因子）穿完整门禁：预注册 H 卡（跑数前哈希
登记）→ 沙盒引擎（因子即代码，无前视）→ 门禁独立复算（1e-12）→
三个注入伪造全部被拒 → 前瞻主张结算审计。

**讲词（最有冲击力的一段）**：
1. 判定是 not_replicated——D1 方向、D2 单调性都失败。我们如实展示
   复现失败，因为判定由预注册规则机械产生，没有人工修饰空间。
2. 三个注入（改数/换窗/换宇宙）全部被门禁拒绝，字段名都点出来了；
3. **无门禁对照组**：同一份改数在没有门禁的路径下原样落盘——这就
   是"没有这套机制会发生什么"的直接证据。
4. 结算：主张登记在数据到达前，尾段数据逐行校验后审计复算。

**金句**：a fail with real metrics beats a fabricated pass.

## Stage 4 — 汇总

`DEMO_REPORT.md` 一页收尾，所有数字机器发射，散文不自造数字。

## 常见提问与答法

**Q: 复现失败了，这框架有什么用？**
A: 复现失败是市场事实，框架的价值是让这个失败可机器复核、可归因
（D3 把量级差异归因到样本期与宇宙），并快速告诉我们该去哪找活着的
信号（Stage 1 幸存者）。

**Q: 数据是哪来的？能复现吗？**
A: `scripts/fetch_ashare_raw.py`（断点续传）→ `build_replication_fixture.py`
（确定性物化）→ 入库即钉死。CI 里任何人可双跑 diff 验证字节一致。

**Q: 门禁会不会拖慢研究？**
A: 恰相反——分级验证：快验证 22 秒淘汰 17 个，重门禁只跑值得的。
防造假的成本被前置到"最后一公里"。

**Q: factorzoo 的因子会不会有前视？**
A: 滚动窗口只用到当日及以前（与复现平面同一约定），月度评估在月末
截面做，因子值与下月收益的配对由 `monthly_ic_series` 的双实现复算。
